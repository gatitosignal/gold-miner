# 图片批量压缩工具

这是一个独立的 Windows 图片压缩工具，不会向黄金矿工网页引入任何 Python 依赖，也不会直接覆盖原图。

## 双击启动

1. 安装 Python 3.10 或更高版本，安装时勾选“Add Python to PATH”。
2. 双击 `start.bat`。
3. 第一次启动会在本目录创建 `.venv` 并自动安装 Pillow，之后可直接打开。

## 使用方法

1. 点击“输入文件夹”右侧的“选择…”，选择包含照片的文件夹。
2. 选择一个不同的输出文件夹。未手动选择时，会建议使用“原文件夹名_compressed”。
3. 选择预设或自行填写最长边、质量和输出格式。
4. 点击“开始压缩”，等待进度条完成。
5. 界面底部会显示压缩前后大小、压缩比例以及失败文件的原因。

工具会递归处理子文件夹并保留相对目录结构，支持 PNG、JPG、JPEG 和 WebP。图片会使用 LANCZOS 等比缩小，不裁剪、不拉伸、小图不放大；EXIF 方向会自动校正，默认不写入多余 EXIF。WebP/PNG 会保留透明通道，透明图片选择 JPEG 时会明确报错而不会生成黑色背景。

如果同一目录中存在同名但不同扩展名的图片，输出文件会自动添加 `_2`、`_3`，不会覆盖。若压缩结果更大且输入输出格式相同，可保留输出目录中的较小原文件。

## 预设

- 极速手机模式：最长边 320px，质量 45。
- 推荐手机模式：最长边 360px，质量 55（默认）。
- 清晰模式：最长边 600px，质量 70。

这些预设主要针对照片、四选一图片和奖励内容。不要把整个游戏 `assets` 文件夹直接作为输入；矿工人物、按钮、绳索、透明精灵和动画素材需要按实际 Canvas 绘制尺寸单独评估。

## 命令行（可选）

```powershell
python compressor.py "输入文件夹" "输出文件夹" --max-edge 360 --quality 55 --format WEBP
```
